Connecting real Google Finance data

Google doesn't provide a public API for Google Finance, so this page reads from a Google Sheet instead — the standard, reliable way to pull live GOOGLEFINANCE() data into a webpage.

  1. Make a copy of a Google Sheet and build columns using formulas like =GOOGLEFINANCE("AAPL","price"), =GOOGLEFINANCE("AAPL","changepct"), and a 1-year-ago price via =GOOGLEFINANCE("AAPL","price",TODAY()-365) to compute yearly change. Dividend yield isn't a live GOOGLEFINANCE attribute, so enter it manually or pull it from your broker.
  2. File → Share → Publish to web, choose the relevant sheet, and select Comma-separated values (.csv).
  3. Paste the published CSV URL into the SHEET_CSV_URL constant at the top of script.js.
  4. Reload — the page will fetch and parse that CSV automatically, and fall back to the demo figures if the fetch fails.
